Accessibility statement

We want everyone to be able to use this site, whatever device, browser, or assistive technology they rely on.

1. Our target

This site aims to meet the Web Content Accessibility Guidelines (WCAG) 2.2 at Level AA.

2. Current status

Partially conformant. Parts of the site do not yet meet the target. They are listed under known limitations below.

3. What works today

  • Every page has one main heading, a page title, and a set language.
  • Pages reflow on a 320px wide screen without sideways scrolling.
  • Contact form fields have visible labels, and the send status is announced to screen readers.
  • Animation is reduced when your device asks for reduced motion.
  • The cookie banner and its choices can be used with a keyboard alone.

4. Known limitations

  • Low contrast text. Some small grey text on tinted panels (the feature lists on the Software page, and the placeholder labels in project screenshots on the Websites page) is below the 4.5:1 contrast ratio. (WCAG 1.4.3)
  • No skip link. Keyboard users have to tab through the header on every page to reach the content. (WCAG 2.4.1)
  • Heading levels. Some pages jump from the main heading to a third-level heading. (WCAG 1.3.1)
  • Header landmark. The site header isn't marked up as a header landmark, so screen readers don't list it as one.
  • Playground canvas experiments. Sparks, Draw, and Jellyfish need a mouse or touch screen, and none of the four experiments can be read by a screen reader. Muncher can be played with a keyboard. The build notes beside the canvas describe each one in text.
  • Screen reader testing. A full pass with VoiceOver and NVDA has not been done yet.

5. Content we don't control

Client websites shown in our work, the Freelancer OS demo, and the visual HTML editor are separate sites. They are not covered by this statement.

6. Report a barrier

If something on this site doesn't work for you, email hello@srcs.online with the page address and what happened. We'll reply within [CLIENT TO SUPPLY: response window] and, where we can, send you the information in a format that works for you.

7. How we tested

Most recent audit: 27 September 2026. Every page was checked with the axe-core automated rules (WCAG 2.2 A and AA) in Chromium, in both the day and evening themes, at desktop width and at 320px.

This statement was prepared on 27 September 2026 and will be reviewed after each significant change to the site.
